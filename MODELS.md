# 3D Model References

This page lists external mechanical references considered during development of
the NFC Vinyl Player. **This repository branch contains no 3D model files.**
The links below point to third-party pages; they are references, not included
assets, verified downloads, or confirmation that a model is used in the build.

The current mechanical concept uses an N20 geared motor, a spindle/drive
interface, a turntable, and an enclosure for the ESP32/NFC/audio electronics.
Compatibility with the actual parts has not been established for the linked
models.

## Rights and suitability

This list does not state or imply that a linked model is free to download,
modify, or redistribute. Check the current terms on the source page for each
model before downloading, adapting, sharing, or publishing model files. A
personal-use allowance or free download does not necessarily permit public
redistribution.

Before adapting any model, verify motor dimensions, shaft geometry, bearing
dimensions, platter size, mounting holes, enclosure clearances, and fit with
the actual electronics and mechanical parts. These links are starting points,
not approved drop-in parts or a validated mechanical design.
